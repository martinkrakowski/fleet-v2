What this draft leaves out on purpose
  • No “system online” pill, no approval rate, no average handling time. The header counts work, not health.
  • No one-key approve or reject, and no hotkey that answers a question. A signed answer is a scoped decision and it is given in Waves.
  • No generic task queue. The home page is attempts, each with five runner facts kept apart. Unknown is its own state.
  • No button appears unless the API said that operation is legal for this attempt. What is not offered is said in words.
  • Nothing on the Brief or Knowledge page writes a policy. A policy proposal leaves the product.
  • 501 renders as “not implemented on this station”; 409 on an unknown outcome renders as the amber unknown. A capped or offline station is a note, never an empty table that looks like “nothing running”.
  • Arrow keys move the selection; Enter opens the record under focus. No key performs an operation.
  • No live host, no provider key, no remote port that answers. Every value is read from a fixture shaped like the brief package, the five-fact observation and the worktree inspection. The refresh cadence advances a virtual clock; the silent runner stays unknown — this page never upgrades a fact by itself.
