## Round 1 Findings & Amendments Applied

1. **Private SSH alias default (`host="${OCM_HOST:-m}"`):**
   - **Finding:** `m` is an operator-local `~/.ssh/config` alias. Defaulting `host` to `m` in product code violates the rule against hardcoding host aliases.
   - **Amendment:** Changed `bin/ocm-run` to `host="${OCM_HOST:-}"`. If `127.0.0.1:$port` is not already listening and `OCM_HOST` is empty, `bin/ocm-run` exits `2` with `ocm-run: server not listening on 127.0.0.1:$port and OCM_HOST is not set`.

2. **Model-specific variant rewrite (`nvidia/*:low) variant=none`):**
   - **Finding:** Seat/provider policy (`nvidia/*:low -> none`) belongs in operator configuration (`FLEET_RUNNER_VARIANT=none`), not inside reusable product code.
   - **Amendment:** Removed the `case "$model:$variant"` block from `fleet-v2/bin/ocm-run`; `bin/ocm-run` forwards `--variant` verbatim when provided.

3. **Hexagen-owned barrel and `apps/cli/package.json` `bin` map:**
   - **Finding:** `packages/work-execution/src/index.ts` carries `// @generated by @hexagen/sync` and fails `yarn sync:check` if hand-edited; `"ocm-run": "../../bin/ocm-run"` in `apps/cli/package.json` traverses outside the package root.
   - **Amendment:** Kept `DEFAULT_OCM_RUN_PATH` internal to `packages/work-execution/src/infrastructure/adapters/execution-runner-adapter.ts` (resolved via `fileURLToPath(new URL("../../../../../bin/ocm-run", import.meta.url))` with `process.env.FLEET_OCM_RUN_BIN` override) and left `packages/work-execution/src/index.ts` and `apps/cli/package.json` untouched.

4. **`OCM_HOST` vs `FLEET_WORKTREE_SSH_HOST` separation:**
   - **Finding:** Falling back `OCM_HOST` to `FLEET_WORKTREE_SSH_HOST` conflates the opencode server tunnel host with the git worktree SSH host.
   - **Amendment:** Added `remoteHost?: string` on `ExecutionRunnerAdapterOptions` wired strictly from `options.remoteHost ?? process.env.OCM_HOST` and documented `OCM_HOST` and `FLEET_OCM_RUN_BIN` in `AGENTS.md` and `docs/architecture.md`.

5. **Subprocess test isolation:**
   - **Amendment:** Updated the plan's test steps so `apps/cli/test/cli-workflow.test.ts` passes `runnerBin: path.join(binDir, "ocm-run")` to `runCli()` (or sets `FLEET_OCM_RUN_BIN`), and the `--attach=bad` test unsets `OCM_PORT` so the usage validation check is what exits `2`.
