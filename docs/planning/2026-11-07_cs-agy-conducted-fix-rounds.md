## 2. Design

### 2.1 Branch handoff there and back (bare clone, host-mapped worktree path, fetch back)

All four stages of [`bin/agy-round`](../../bin/agy-round#L1-L410) move into typed `@fleet/work-execution` ports and infrastructure adapters over [`CommandExecutorPort`](../../packages/work-execution/src/application/ports/out/CommandExecutorPort.out-port.ts) — no shell script is carried into v2:

1. **Relay topology**: Each `opencode` lane-host project clone declares `barePath` (a local bare relay repository on that host, never checked out and holding no hooks or remotes). The `agy-lanes` container host entry in [`ProjectProfile`](../../packages/operator-coordination/src/domain/entities/ProjectProfile.ts#L118-L157) declares `{ path, worktreeRoot }` inside the container.
2. **Host-mapped path & admission before seeding**: When [`fixDispatchStep`](../../packages/work-execution/src/application/use-cases/advance-lane-run/review-fix.ts#L1617-L1691) selects an `agy` seat (`tool === 'agy'`), admission runs against `agy` candidate hosts first (`ReserveExecutionCapacityUseCase` / `LaneRunAdmissionAdapter.admit`) to allocate `<agyClone.worktreeRoot>/<attemptDigest>`. [`LaneRunAdmissionAdapter.admit`](../../packages/work-execution/src/infrastructure/adapters/LaneRunAdmissionAdapter.adapter.ts#L159-L210) keeps `opencode` attempts (`first-pass` and `fx-glm`) pinned to `firstAttempt`'s `opencode` host and `firstAttempt.worktreePath`, while permitting `agy` fix attempts to reserve an `agy` host and `<agyClone.worktreeRoot>/<attemptDigest>`.
3. **Outbound handoff (`AgyBranchHandoffPort.seedContainerClone`)**:
   - Verify on the canonical lane-host worktree (`firstAttempt.worktreePath`) that `refs/heads/fleet/<runId>` resolves to `expectedParentHead = prior.artifacts.headCommit` (40-hex SHA; never `HEAD`).
   - Push `+expectedParentHead:refs/heads/fleet/<runId>` from the lane-host worktree into `barePath`, then stream/push that single ref (`git bundle create -` over stdin/stdout or SSH-aliased `git push`, zero container outbound network/SSH trust) into a fresh standalone repository at `<agyClone.worktreeRoot>/<attemptDigest>` on `agy-lanes` checked out on `fleet/<runId>` at `expectedParentHead`, with `hooksPath=/dev/null` and no remotes.
   - Write `.lane/brief.md` and `.lane/brief-manifest.json` onto `<agyClone.worktreeRoot>/<attemptDigest>` on `agy-lanes` (never touching `firstAttempt.worktreePath` on the `opencode` host).
4. **Inbound handoff (`AgyBranchHandoffPort.fetchCommitBack`)**:
   - After post-run guard verification and `edit-only` commit on `agy-lanes` produce `newHeadCommit` (`!== expectedParentHead`, with `git merge-base --is-ancestor expectedParentHead newHeadCommit`), stream `refs/heads/fleet/<runId>` back from `<agyClone.worktreeRoot>/<attemptDigest>` into `barePath`, fetch `barePath` into the lane-host clone, and fast-forward `firstAttempt.worktreePath` (`git update-ref` / clean-worktree `git merge --ff-only` CAS-guarded from `expectedParentHead` to `newHeadCommit`).
   - Remove `<agyClone.worktreeRoot>/<attemptDigest>` on `agy-lanes` once `firstAttempt.worktreePath` is verified at `newHeadCommit`.

### 2.2 Where the `edit-only` commit happens

The `edit-only` commit runs at the start of [`performCollect`](../../packages/work-execution/src/application/use-cases/advance-lane-run/collect-gate.ts#L94-L124) on `agy-lanes` (`attempt.runner`, `attempt.worktreePath`), **strictly after** post-run `--check-hashes` passes and **strictly before** `fetchCommitBack` and [`CollectAttemptArtifactsUseCase`](../../packages/work-execution/src/application/use-cases/CollectAttemptArtifactsUseCase.use-case.ts#L141-L150):

- [`CommitEditOnlyAttemptUseCase`](../../packages/work-execution/src/application/use-cases/CommitEditOnlyAttemptUseCase.use-case.ts#L217-L270) runs [`LaneDiffCheckPort`](../../packages/work-execution/src/infrastructure/adapters/LaneDiffCheckAdapter.adapter.ts#L1-L80) against `attempt.handoff.expectedParentHead` (protected paths, scope, secret shapes, git config/hooks) and commits staged lane edits on `agy-lanes` with trailer `Fleet-Attempt-Id: <attemptId>`.
- **Empty diff (`nothing-to-commit`)**: `runCollectBody` does **not** call `CollectAttemptArtifactsUseCase` on the unchanged prior HEAD. Instead, it marks `fx-agy-flash` runtime-`unhealthy`, updates the attempt with `stopReason: 'no-commit'` (`artifacts: undefined`), removes the clean container clone, and lets [`collectingRules`](../../packages/work-execution/src/domain/lane-run-decider.ts#L829-L835) transition the run to `seat-failed` (never `fix-no-progress`).
- **Committed (`committed` / `already-committed` on crash retry)**: `performCollect` runs `fetchCommitBack` into `handoff.laneWorktreePath`, then runs `CollectAttemptArtifactsUseCase` against `laneWorktreeOf(attempt)` on the canonical `opencode` host.

### 2.3 How `--check-hashes` is configured and enforced

- **Configuration**: Extend [`AgyHostRunnerSection`](../../packages/installation/src/types.ts#L188-L192) (`hosts.<name>.runner` when `kind === 'agy'` and `mode === 'edit-only'`) with a required-for-conducted-agy `guard` object:
  - `sshHost: string` (the outer container-host SSH alias, distinct from the unprivileged `agy-lanes` SSH alias, matching `AGY_ROUND_GUARD_SSH` in [`bin/agy-round`](../../bin/agy-round#L19-L26));
  - `command: string` and optional `args?: readonly string[]` (fixed executable path + argv array; `--check-hashes` must be present in `args`, shell metacharacters and whitespace-split strings are refused at parse time);
  - `settleSeconds?: number` (integer `0..30`, default `2`, matching `AGY_ROUND_SETTLE`).
- **Enforcement (`AgyGuardPort` / `AgyGuardAdapter`)**:
  1. **Pre-run**: Before seeding `<agyClone.worktreeRoot>/<attemptDigest>` or invoking [`bin/agy-run`](../../bin/agy-run), `AgyGuardAdapter` executes `[command, ...args]` over `sshHost` via `CommandExecutorPort` (argv-only, no shell). Non-zero exit or timeout refuses handoff before container bytes are written, marks `fx-agy-flash` runtime-`unhealthy`, and parks or pivots per Owner Decision D2.
  2. **Post-run**: Once `agy-run` has exited (and `terminateAttemptProcessTree` has reaped any stray worktree children), `performCollect` waits `settleSeconds`, then runs `[command, ...args]` again **before** reading diff bytes, committing, or fetching back. Any non-zero exit or timeout refuses collection, leaves `firstAttempt.worktreePath` untouched, marks `fx-agy-flash` runtime-`unhealthy`, and parks the run `security-hold` for owner inspection. Both guard timestamps/digests are recorded in the execution journal and `AttemptHandoffRecord`.

### 2.4 Runtime seat health and non-spending fallback to `fx-glm`

- **Store & Port**: Add `RuntimeSeatHealthPort` (`readUnhealthySeatIds()`, `markSeatUnhealthy({ seatId, reason, attemptId, runId, recordedAtIso })`, `resetSeatHealth({ seatId })`) backed by `SeatHealthStoreAdapter` writing `<stateDir>/seat-health.json` under `withFileLock` and registered in [`WORK_EXECUTION_STATE_FILES`](../../packages/work-execution/src/infrastructure/adapters/state-files.ts#L1-L122) and [`DRY_RUN_STORE_FILES`](../../apps/cli/src/conductor.ts#L1304-L1313). Operator config in `installation.yaml` is never mutated at runtime.
- **Effective health**: Seat selection in [`implementerSeatOf`](../../packages/work-execution/src/application/use-cases/advance-lane-run/facts.ts#L345-L349) and [`fixDispatchStep`](../../packages/work-execution/src/application/use-cases/advance-lane-run/review-fix.ts#L1618-L1624) supplies `unhealthySeatIds = union(staticCatalogUnhealthy, runtimeStoreUnhealthy)` and `unavailable = coolingSeatIds(...)`.
- **Triggers that mark `fx-agy-flash` unhealthy and pivot without spending the round**:
  1. **`429` (`rate-limited`)**: Classified from `agy-run` output/exit in [`AgyRunnerAdapter`](../../packages/work-execution/src/infrastructure/adapters/AgyRunnerAdapter.adapter.ts) / [`ReconcileAttemptUseCase`](../../packages/work-execution/src/application/use-cases/ReconcileAttemptUseCase.use-case.ts) -> `stopReason: 'rate-limited'`.
  2. **Timeout (`timeout`)**: Either `agy-run` `--print-timeout` exit `124` ([`bin/agy-run:476-486`](../../bin/agy-run#L476-L486)) or conductor deadline `stopAct` ([`lane-run-decider.ts:787-792`](../../packages/work-execution/src/domain/lane-run-decider.ts#L787-L792)) records `stopReason: 'timeout'`.
  3. **Empty diff (`no-commit`)**: `CommitEditOnlyAttemptUseCase` returns `nothing-to-commit` -> `stopReason: 'no-commit'`.
- **Why the round is not spent**: [`performDispatch`](../../packages/work-execution/src/application/use-cases/advance-lane-run/prepare-dispatch.ts#L787-L791) raises `record.round` (e.g. `0 -> 1`) via [`raiseRoundAndCursor`](../../packages/work-execution/src/application/use-cases/advance-lane-run/prepare-dispatch.ts#L1287-L1319) when `fx-agy-flash` dispatches. On `rate-limited`, `timeout`, or `no-commit`, the run enters `seat-failed`; [`seatFailedRules`](../../packages/work-execution/src/domain/lane-run-decider.ts#L796-L812) prepares and dispatches `fx-glm` (`seatIndex: 1`) at `decision.round = record.round` (`1`), so `Math.max(record.round, decision.round)` stays `1` and `maxFixRounds` is untouched.

### 2.5 Attempt records for two hosts

Keep [`AttemptRecord.worktreePath`](../../packages/work-execution/src/domain/execution-records.ts#L311) and [`AttemptRecord.runner`](../../packages/work-execution/src/domain/execution-records.ts#L324) naming the **execution host** (`agy-lanes` and `<agyClone.worktreeRoot>/<attemptDigest>`) so [`DispatchAttemptUseCase`](../../packages/work-execution/src/application/use-cases/DispatchAttemptUseCase.use-case.ts#L322-L328), [`ReconcileAttemptUseCase`](../../packages/work-execution/src/application/use-cases/ReconcileAttemptUseCase.use-case.ts#L179-L183), [`StopAttemptUseCase`](../../packages/work-execution/src/application/use-cases/StopAttemptUseCase.use-case.ts#L196-L205), `terminateAttemptProcessTree`, and `CommitEditOnlyAttemptUseCase` keep their single-target invariants unchanged. Add an optional `handoff?: AttemptHandoffRecord | null` on [`AttemptRecord`](../../packages/work-execution/src/domain/execution-records.ts#L303-L359):

```ts
export interface AttemptHandoffRecord {
  readonly laneHost: AttemptRunnerRecord;       // canonical opencode host coordinates
  readonly laneWorktreePath: string;            // firstAttempt.worktreePath on laneHost
  readonly bareClonePath: string;               // relay bare repo on laneHost
  readonly expectedParentHead: string;          // 40-hex prior.artifacts.headCommit
  readonly preGuardVerifiedAtIso: string | null;
  readonly postGuardVerifiedAtIso: string | null;
  readonly fetchedHeadCommit: string | null;    // set once laneWorktreePath fast-forwards
}
```

A pure helper `laneWorktreeOf(attempt)` returns `{ runner: attempt.handoff?.laneHost ?? attempt.runner, worktreePath: attempt.handoff?.laneWorktreePath ?? attempt.worktreePath }`. Post-fetch consumers — [`CollectAttemptArtifactsUseCase`](../../packages/work-execution/src/application/use-cases/CollectAttemptArtifactsUseCase.use-case.ts#L141-L150), gate evaluation ([`work-execution.ts:511-527`](../../apps/cli/src/composition/work-execution.ts#L511-L527)), review diffing ([`review-fix.ts:116-143`](../../packages/work-execution/src/application/use-cases/advance-lane-run/review-fix.ts#L116-L143)), forge push ([`work-execution-hosts.ts:286-392`](../../apps/cli/src/composition/work-execution-hosts.ts#L286-L392)), and [`ReapLaneWorktreesUseCase`](../../packages/work-execution/src/application/use-cases/ReapLaneWorktreesUseCase.use-case.ts#L43) — route through `laneWorktreeOf(attempt)`. For `opencode` attempts (`first-pass` and `fx-glm`), `handoff` is `null` and behaviour is identical to today.

### 2.6 Seat-plan expressibility (`opencode` first pass, `agy` fix seat)

Rather than widening [`AttemptSeatOverrideRecord`](../../packages/work-execution/src/domain/execution-records.ts#L188-L195) to override runner tools mid-attempt, each fix round already authors its own frozen brief manifest in [`briefRequestFromManifest`](../../packages/work-execution/src/application/use-cases/advance-lane-run/review-fix.ts#L1022-L1069):

1. [`briefRequestFromManifest`](../../packages/work-execution/src/application/use-cases/advance-lane-run/review-fix.ts#L1022-L1069) stamps `modelAssignment` from the selected fix seat (`{ model: seat.model, seatTool: seat.tool, ...(seat.variant ? { variant: seat.variant } : {}), ...(seat.agent ? { agent: seat.agent } : {}) }`), so an `agy` fix brief carries `seatTool: 'agy'` and omits `agent` and `variant`, while an `fx-glm` fallback brief carries `seatTool: 'opencode'` and `agent: 'lane-glm'`.

In `installation.yaml` (`seats` + `chains.fix`, compiled by [`seatPlanFromCatalog`](../../packages/work-execution/src/domain/seat-selection.ts#L987-L1059)) and in `--brief-request` payloads passed to [`conductor start`](../../apps/cli/src/conductor.ts#L696-L703):

(In `installation.yaml`, `chains.fix` step 1 declares `triggers: ['429', 'timeout', 'no-commit']`, which [`CATALOG_TRIGGER_TO_STOP_REASON`](../../packages/work-execution/src/domain/seat-selection.ts#L748-L754) maps to `on: ['rate-limited', 'timeout', 'no-commit']`.)

- **Round 2+ re-entry rule**: When Round 1 succeeds on `fx-agy-flash` (`stopReason: 'none'`) and review requests Round 2, [`selectSeat`](../../packages/work-execution/src/domain/seat-selection.ts#L188-L198) starts at `fx-glm`, sees `on` unsatisfied (`seenReasons = {'none'}`), and wraps back to `fx-agy-flash` (`seatIndex: 0`), enforcing `fx-agy-flash` on every fix round while healthy.
- **Cross-lane runtime-unhealthy rule**: Update [`implementerSeatBlock`](../../packages/work-execution/src/domain/seat-selection.ts#L116-L138) so when **every** primary seat (`seat.on === undefined`) in `role` is blocked by `unhealthy`, `unavailable`, or `refusedModels`, `on`-gated fallback seats unlock even if the current lane has not yet suffered a failed turn itself. Thus a second lane entering `fix` while `fx-agy-flash` is already runtime-`unhealthy` binds immediately to `fx-glm` without wasting a container handoff.

## 4. Risks and assumptions

- **Crash mid-handoff / idempotence**: A driver crash between `CommitEditOnlyAttemptUseCase` on `agy-lanes` and `fetchCommitBack` onto `laneWorktreePath` leaves the commit in the container clone while `handoff.fetchedHeadCommit` is `null`. `performCollect` must stay idempotent: on retry, `CommitEditOnlyAttemptUseCase` returns `already-committed` with the same `Fleet-Attempt-Id` trailer, post-run `--check-hashes` re-runs, and `fetchCommitBack` completes the CAS fast-forward from `expectedParentHead`.
- **Tampered container git metadata**: Because `agy` runs inside `agy-lanes` as an unprivileged user over a writable working tree, `fetchCommitBack` must verify `git merge-base --is-ancestor expectedParentHead newHeadCommit`, exact single-commit parent `newHeadCommit^1 === expectedParentHead`, and `LaneDiffCheckAdapter` cleanliness **before** updating `refs/heads/fleet/<runId>` on the lane host; non-fast-forward or multi-commit histories are refused and park `security-hold`.
- **Ambiguous executor timeout vs model timeout**: In [`AgyRunnerAdapter`](../../packages/work-execution/src/infrastructure/adapters/AgyRunnerAdapter.adapter.ts#L405-L413), an SSH transport hang during `startSession` is distinct from `bin/agy-run`'s `--print-timeout` (`exit 124`). Only confirmed session/print timeouts (`exit 124` or deadline `StopAttemptUseCase` with confirmed termination receipt) may transition to `seat-failed` (`timeout`); an unconfirmed SSH drop stays `ambiguous` until `inspectWorktreeRun` / `abortWorktreeRun` confirms the container process has ended.
- **Reviewer model-family exclusion**: [`implementerModelsOf`](../../packages/work-execution/src/domain/seat-selection.ts#L345-L362) collects every model that ran or was bound across the lane. When `fx-agy-flash` (`gemini-3.8-flash-high`) runs — even if it fails and `fx-glm` takes over — `gemini-*` and `glm-*` are both recorded in the lane's implementer history, so `chains.reviewer` and `chains['high-risk-reviewer']` must retain at least one non-Gemini, non-GLM reviewer family (e.g. Claude or GPT) to avoid exhausting [`selectReviewSeat`](../../packages/work-execution/src/domain/seat-selection.ts#L294-L339).
- **Assumption on container isolation**: Assumes the `agy-lanes` container already enforces read-only root/tooling mounts checked by `--check-hashes`, has no outbound SSH keys to the lane host or forge, and exposes separate SSH aliases for the unprivileged runner (`hosts.<agy>.ssh`) and the root/host hash verifier (`hosts.<agy>.runner.guard.sshHost`).

## 5. Hard to undo

1. **Persisted `AttemptRecord.handoff` schema in `attempts.json`**: Once live runs write `handoff` onto stored [`AttemptRecord`](../../packages/work-execution/src/domain/execution-records.ts#L303-L359) entries, rolling back code without stripping or tolerating `handoff` will strand in-flight `agy` attempts whose `worktreePath` points into `agy-lanes` rather than the lane host. Keep `handoff` strictly optional on read and immutable once `fetchedHeadCommit` is sealed.
2. **Installation v2 `guard` and project-profile `barePath` keys**: Because [`parse.ts`](../../packages/installation/src/parse.ts#L173-L185) and [`ProjectProfile.ts`](../../packages/operator-coordination/src/domain/entities/ProjectProfile.ts#L118-L157) reject unknown keys fail-closed, writing `hosts.<name>.runner.guard` into `installation.yaml` or `barePath` into stored project profiles prevents downgrading `fleet-v2` binaries past `CS-AGY1` without first removing those keys.
3. **New durable state file `seat-health.json`**: Registered in [`WORK_EXECUTION_STATE_FILES`](../../packages/work-execution/src/infrastructure/adapters/state-files.ts); its on-disk versioned envelope (`version: 1`) becomes part of the `--state-dir` contract alongside `reservations.json` and `seat-observations.json`.
4. **Canonical branch fast-forward on the lane host**: Once `fetchCommitBack` advances `refs/heads/fleet/<runId>` on `firstAttempt.worktreePath`, that commit is part of the lane's git history and review/gate audit trail; `fetchCommitBack` must never run until both `--check-hashes` and `LaneDiffCheckAdapter` have passed.
